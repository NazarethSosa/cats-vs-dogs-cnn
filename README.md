# Clasificación de Imágenes: Gatos vs Perros con CNN

Proyecto final del curso **Manejo de Datos para la Inteligencia Artificial**  
Universidad Galileo — Guatemala, 2026

**Autores:** Alejandra Nazareth Sosa Carrillo · José Fernando Chalo Sajquín

---

## Descripción

Clasificador binario de imágenes entrenado desde cero usando una Red Neuronal 
Convolucional (CNN) sobre el dataset Microsoft Cats vs Dogs (Kaggle).  
El modelo alcanza **90.98% de accuracy** y **AUC-ROC de 0.9683** en validación.

## Resultados

| Métrica        | Valor  |
|----------------|--------|
| Accuracy       | 0.9098 |
| Precision      | 0.9133 |
| Recall         | 0.9093 |
| F1-Score       | 0.9113 |
| AUC-ROC        | 0.9683 |

## Dataset

[Microsoft Cats vs Dogs — Kaggle](https://www.kaggle.com/datasets/shaunthesheep/microsoft-catsvsdogs-dataset/data)

## Tecnologías

Python · TensorFlow · Keras · PIL · imagehash · scikit-learn · Matplotlib
